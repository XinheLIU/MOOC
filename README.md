# MOOC Knowledge Base

> **AI-powered intelligent knowledge base** with curated course materials from top universities

## 🌟 Overview

This repository contains **19+ courses** from leading universities and platforms, organized into **5 learning domains**. The knowledge base is structured for both personal learning and public access, with plans for AI-powered search and discovery features.

## 📚 Repository Structure

The repository is organized by learning domains:

```
MOOC/
├── 00_Knowledge-Base-Guide/          # Start here! User guides and learning paths
├── 01_AI-and-Machine-Learning/      # 9 courses: ML, Deep Learning, AI
├── 02_Programming/                   # 4 courses: Python, C, MATLAB, CS fundamentals
├── 03_Data-Science-and-Analysis/     # 1 course: Data analytics
├── 04_Math-and-Statistics/           # Statistics and mathematical foundations
├── 05_Software-Design-and-Architecture/ # 2 courses: Design patterns, algorithms
└── 06_Other-Open-Courses/            # Additional courses
```

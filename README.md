# MOOC Knowledge Base

> **AI-powered intelligent knowledge base** with curated course materials from top universities

## 🌟 Overview

This repository contains **20+ courses** from leading universities and platforms, organized into **5 learning domains**. The knowledge base is structured for both personal learning and public access, with plans for AI-powered search and discovery features. **GenAI & Agent** is the first domain, followed by classic AI/ML, data science, programming, and software design.

## 📚 Repository Structure

The repository is organized by learning domains:

```
MOOC/
├── Knowledge-Base-Guide/           # Start here! User guides and learning paths
├── 01_GenAI-and-Agent/             # GenAI, agents, LLM apps (DeepLearning.AI, Anthropic, LangChain, etc.)
├── 02_AI-and-Machine-Learning/     # Classic ML & DL (Stanford, Coursera, HSE, etc.)
├── 03_Data-Science-and-Analysis/   # Data analytics, statistics (Google, UCSC)
├── 04_Programming/                 # CS fundamentals, Python, MATLAB (Harvard, UMich, Vanderbilt, NJU)
└── 05_Software-Design-and-Architecture/  # Design patterns, algorithms (Alberta, PKU)
```
